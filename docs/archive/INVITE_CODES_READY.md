## 📝 Как это работает

### Для пользователя:
1. Заходит на сайт → автоматически редирект на `/invite`
2. Вводит код формата XXX-XXX
3. Код проверяется → сохраняется в cookies
4. Редирект на `/login` → авторизация через Telegram
5. Получает доступ к приложению ✨

### Для тебя:
- Все 25 кодов в файле `invite-codes-2025-12-25.txt`
- Каждый код работает 1 раз
- Раздай коды тестерам
- В БД сохраняется, кто какой код использовал

## 🎯 Быстрый старт

### Раздать коды тестерам
Отправь им коды из файла `invite-codes-2025-12-25.txt`

### Сгенерировать больше кодов
```bash
node scripts/generate-invite-codes.js 10
```

### Проверить использование кодов
```bash
npx prisma studio
# Открой таблицу invite_codes
```

### Отключить систему инвайт-кодов (когда закончится бета)
Закомментируй проверку в `src/middleware.ts` (строки 46-51)
