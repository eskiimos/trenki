# 🔐 Безопасная авторизация с подтверждением

## ✅ Что улучшили

Теперь Telegram бот **требует явного подтверждения** от пользователя перед авторизацией.

## 🔒 Новый безопасный flow

### 1. Генерация токена
```
Веб-страница → Генерирует login_token
             → Показывает кнопку "Войти через Telegram"
             → Начинает polling (проверка каждые 2 сек)
```

### 2. Переход в бота
```
Пользователь → Нажимает кнопку
             → Открывается t.me/trenkiapp_bot?start=login_{token}
             → Бот получает /start login_{token}
```

### 3. Запрос подтверждения (НЕ активирует сразу!)
```
Бот → Показывает сообщение:
      "🔐 Подтверждение входа
       Вы хотите войти в приложение Trenki с вашего браузера?
       ⚠️ Нажимайте кнопку только если вы сами запросили вход!"
      
Бот → Показывает кнопки:
      [✅ Да, это я! Подтвердить вход]  ← callback: confirm_login:{token}
      [❌ Отменить]                     ← callback: cancel_login:{token}
```

### 4. Явное подтверждение
```
Пользователь → Нажимает "✅ Да, это я!"
Бот → Обрабатывает callback query
    → Активирует токен (связывает с telegram_id)
    → Показывает: "✅ Вход подтверждён!"
    → Предлагает кнопку "🚀 Открыть Trenki"
```

### 5. Авторизация
```
Веб-страница → Polling обнаруживает активацию токена
             → Получает telegram_id
             → Загружает данные пользователя
             → Сохраняет сессию
             → Редирект на главную или /onboarding
```

## 🛡️ Защита от атак

### Защита от фишинга
- ✅ Пользователь видит **явное предупреждение**
- ✅ Требуется **активное действие** (нажатие кнопки)
- ✅ Можно **отменить** запрос

### Защита от перехвата токенов
- ✅ Токены **одноразовые** (удаляются после использования)
- ✅ Срок действия **5 минут**
- ✅ Токен активируется **только** после подтверждения

### Защита от подмены
- ✅ Токен связывается с **конкретным telegram_id**
- ✅ Невозможно использовать токен от другого пользователя
- ✅ Callback query содержит **telegram_id** отправителя

## 📝 Код реализации

### Обработка /start в боте

```typescript
if (param && param.startsWith('login_')) {
  const token = param.replace('login_', '');
  
  // НЕ активируем токен сразу!
  const loginMessage = `
🔐 **Подтверждение входа**

Вы хотите войти в приложение **Trenki** с вашего браузера?

⚠️ Нажимайте кнопку только если вы сами запросили вход!
  `;
  
  const keyboard = {
    reply_markup: {
      inline_keyboard: [
        [{ 
          text: '✅ Да, это я! Подтвердить вход',
          callback_data: `confirm_login:${token}`
        }],
        [{ 
          text: '❌ Отменить',
          callback_data: `cancel_login:${token}`
        }]
      ]
    }
  };
  
  await sendMessage(chatId, loginMessage, keyboard);
}
```

### Обработка подтверждения

```typescript
if (data?.startsWith('confirm_login:')) {
  const token = data.replace('confirm_login:', '');
  const telegramId = callbackQuery.from.id;
  
  // Активируем токен ТОЛЬКО после подтверждения
  const response = await fetch('/api/auth/activate-token', {
    method: 'POST',
    body: JSON.stringify({ token, telegramId })
  });
  
  if (response.ok) {
    const successMessage = `
✅ **Вход подтверждён!**

Вы успешно авторизовались в приложении **Trenki**.

Теперь вы можете вернуться в браузер - вход будет выполнен автоматически.
    `;
    
    await editMessage(chatId, messageId, successMessage);
  }
}
```

### Обработка отмены

```typescript
if (data?.startsWith('cancel_login:')) {
  const cancelMessage = `
❌ **Вход отменён**

Запрос на вход был отменён.

Если вы не запрашивали вход, всё в порядке - ваша безопасность не нарушена.
  `;
  
  await editMessage(chatId, messageId, cancelMessage);
}
```

## 🎯 UX преимущества

### Для пользователя:

- ✅ **Безопасно** - явное предупреждение о фишинге
- ✅ **Быстро** - один клик для подтверждения

### Для разработчика:
- ✅ **Просто** - callback query вместо сложной логики

## 📱 Тестирование

### Успешный сценарий:
1. Откройте https://trenki.vercel.app/login
2. Нажмите "Войти через Telegram"
3. В боте увидите запрос подтверждения
4. Нажмите "✅ Да, это я!"
5. Автоматический редирект на главную

### Сценарий отмены:
1. Откройте https://trenki.vercel.app/login
2. Нажмите "Войти через Telegram"
3. В боте нажмите "❌ Отменить"
4. Токен не активируется, страница продолжает polling
5. Токен истечёт через 5 минут

### Сценарий фишинга:
1. Кто-то отправляет вам: t.me/trenkiapp_bot?start=login_fake123
2. Вы открываете ссылку
3. Видите предупреждение: "⚠️ Нажимайте только если вы сами запросили"
4. Вы НЕ нажимаете кнопку или нажимаете "❌ Отменить"
5. Атака предотвращена! ✅
