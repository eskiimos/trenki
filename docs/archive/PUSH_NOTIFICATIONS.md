# Push-уведомления в PWA

## Реализованная функциональность

### ✅ Что сделано:

1. **База данных**:
   - Модель `PushSubscription` для хранения подписок пользователей
   - Модель `PushNotification` для истории отправленных уведомлений
   - Миграция применена к базе данных

2. **Service Worker** (`/public/sw.js`):
   - Обработка входящих push-уведомлений
   - Отображение уведомлений с кастомными данными (title, body, icon, url)
   - Обработка кликов по уведомлениям с переходом на нужную страницу

3. **API Endpoints**:
   - `GET /api/push/subscribe` - получение публичного VAPID ключа
   - `POST /api/push/subscribe` - сохранение подписки пользователя
   - `DELETE /api/push/subscribe` - удаление подписки
   - `POST /api/push/send` - отправка push-уведомлений
   - `GET /api/push/send` - получение истории отправленных уведомлений

4. **Админ-панель** (`/admin/notifications`):
   - Форма создания уведомления (заголовок, текст, иконка, URL)
   - Кнопка отправки всем подписчикам
   - Статистика активных подписок
   - История отправленных уведомлений

5. **Клиентская часть**:
   - Хук `usePushNotifications` для управления подписками
   - Кнопка включения/отключения уведомлений в профиле пользователя
   - Автоматический запрос разрешения на уведомления

## 🚀 Как протестировать:

### Шаг 1: Подписаться на уведомления
1. Откройте приложение в браузере (лучше Chrome/Edge)
2. Перейдите в профиль (`/profile`)
3. Нажмите кнопку "🔔 Включить уведомления"
4. Разрешите уведомления в браузере

### Шаг 2: Отправить тестовое уведомление
1. Перейдите в админку (`/admin`)
2. Откройте "📬 Уведомления" (`/admin/notifications`)
3. Заполните форму:
   - **Заголовок**: "Новая тренировка!"
   - **Текст**: "Доступна новая тренировка по хоккею"
   - **URL**: `/video` (куда переходить при клике)
4. Нажмите "Отправить всем"
5. Должно появиться уведомление даже если приложение свёрнуто

### Шаг 3: Проверить уведомление
1. Уведомление должно появиться в трее/уведомлениях ОС
2. При клике на уведомление должен открыться указанный URL
3. В админке должна обновиться статистика

## 📱 Где работает:

- ✅ **Chrome/Edge** (Desktop & Android) - полная поддержка
- ✅ **Firefox** (Desktop & Android) - полная поддержка
- ✅ **Safari** (macOS 16.4+, iOS 16.4+) - поддержка добавлена
- ❌ **iOS WebView в Telegram** - не поддерживается (ограничение Apple)

## 🔧 Технические детали:

### VAPID ключи
Уже сгенерированы и находятся в `.env.local`:
- `NEXT_PUBLIC_VAPID_PUBLIC_KEY` - публичный ключ (используется в браузере)
- `VAPID_PRIVATE_KEY` - приватный ключ (используется на сервере)
- `VAPID_SUBJECT` - email для обратной связи

### Структура push-данных
```json
{
  "title": "Заголовок уведомления",
  "body": "Текст уведомления",
  "icon": "/icons/icon-192.png",
  "badge": "/icons/icon-192.png",
  "url": "/video"
}
```

### Автоматическая очистка
Система автоматически удаляет недействительные подписки (410/404 ответы от браузера).

## 📊 Мониторинг:

В админке (`/admin/notifications`) доступна информация:
- Количество активных подписок
- История всех отправленных уведомлений
- Количество успешных доставок для каждого уведомления

## 🎯 Сценарии использования:

1. **Новое видео**: Уведомить всех о новой тренировке
2. **Новый короткий ролик**: Привлечь внимание к shorts
3. **Важные новости**: Анонсы, обновления, акции
4. **Напоминания**: Мотивация к регулярным тренировкам

## ⚠️ Важно:

1. **HTTPS обязателен** - push-уведомления работают только через HTTPS (или localhost)
2. **Разрешение пользователя** - нужно явное согласие пользователя
3. **Ограничения браузера** - количество уведомлений может быть ограничено
4. **Telegram WebView** - push не работает в iOS WebView приложения Telegram
