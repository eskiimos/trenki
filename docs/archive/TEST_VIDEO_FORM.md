## ✅ Тест 1: Создание нового видео

### Шаги:
1. Откройте `/admin/videos`
2. Нажмите "➕ Добавить новое видео"
3. Заполните **вкладку "Основное"**:
   - [ ] Название: "Тест - Разминка динамическая"
   - [ ] URL видео: `https://kinescope.io/test123`
   - [ ] Описание: "Тестовое видео"
   - [ ] Категория: Катание
   - [ ] Сложность: Начальный
   - [ ] Тренер: (выберите любого)
   - [ ] Оборудование: "Коньки"

4. Переключитесь на **вкладку "Алгоритм 2.0"**
5. Откройте **подвкладку "⚙️ Классификация"**:
   - [ ] Тип модуля: Разминка
   - [ ] Тип нагрузки: Динамическая растяжка
   - [ ] Группа мышц: Все тело
   - [ ] Сложность: Новичок
   - [ ] RPE минимум: 3
   - [ ] RPE максимум: 5

6. Переключитесь на **подвкладку "🎯 Цели и возраст"**:
   - [ ] Отметьте возрастные группы: Подростки, Молодые
   - [ ] Отметьте цели: Мощный бросок, Обыграть соперника

7. [ ] Нажмите "Добавить видео"
8. [ ] Проверьте, что появилось сообщение об успехе

### Ожидаемый результат:
✅ Видео создано без ошибок
✅ Все поля сохранены

## 🔍 Критичные поля для алгоритма

**Обязательные для генерации тренировок:**
- ✅ `moduleType` - тип модуля в тренировке
- ✅ `loadType` - тип физической нагрузки
- ✅ `muscleGroup` - направление нагрузки
- ✅ `complexity` - уровень сложности
- ✅ `rpeMin`, `rpeMax` - диапазон интенсивности
- ✅ `ageGroups[]` - целевые возрастные группы
- ✅ `trainingGoals[]` - подходящие цели тренировок

**Если хотя бы одно поле не сохраняется:**
🚨 Алгоритм генерации тренировок не сможет правильно подобрать видео!
