- 👶 Дети (до 12 лет) - `CHILD`
- 🧒 Подростки (13-17 лет) - `TEEN`
- 👨 Молодые (18-35 лет) - `YOUNG_ADULT`

##### Цели тренировок (множественный выбор)
- 🎯 Мощный бросок - `POWERFUL_SHOT`
- ⚡ Обыграть соперника - `OUTRUN_OPPONENT`
- 🏃 Бегать без остановки - `RUN_WITHOUT_STOPPING`
- 💪 Выдерживать силовые - `WITHSTAND_FORCE`
- 🤸 Быть гибким - `BE_FLEXIBLE`
- 🎯 Улучшить технику - `IMPROVE_TECHNIQUE`
- 🩹 Восстановиться после травмы - `RECOVER_FROM_INJURY`

## 🧪 Как проверить

### Создание нового видео

1. Откройте админку: `/admin/videos`
2. Нажмите кнопку "➕ Добавить новое видео"
3. Заполните основные поля (название, URL, тренер и т.д.)
4. Прокрутите вниз до секции **"🎯 Алгоритм 2.0: Таргетинг"**
5. Выберите несколько возрастных групп (например, TEEN + YOUNG_ADULT)
6. Выберите несколько целей тренировок (например, POWERFUL_SHOT + OUTRUN_OPPONENT)
7. Нажмите "Добавить видео"
8. Проверьте в консоли браузера логи с сохраненными данными

### Редактирование существующего видео

1. Найдите видео в списке
2. Нажмите кнопку "✏️ Редактировать"
3. Прокрутите до секции "Алгоритм 2.0: Таргетинг"
4. Если видео уже имеет выбранные группы/цели - они будут отмечены галочками
5. Измените выборки
6. Нажмите "Сохранить изменения"
7. Проверьте, что данные обновились

### Проверка в базе данных

```bash
# Проверить видео с новыми полями
npx prisma studio
```

В Prisma Studio:
1. Откройте таблицу `Video`
2. Найдите созданное/измененное видео
3. Проверьте поля `ageGroups` и `trainingGoals` - должны быть массивы со значениями

### Проверка работы алгоритма

После того как в БД есть видео с заполненными полями:

1. Откройте страницу выбора цели: `/training/select-goal`
2. Выберите цель тренировки
3. Выберите уровень энергии
4. Нажмите "Начать тренировку"
5. API `POST /api/training/generate-v3` должен:
   - Найти видео, соответствующие выбранной цели
   - Отфильтровать по возрастной группе пользователя
   - Применить fallback-систему если точных совпадений нет
   - Вернуть готовую тренировку из 2-4 модулей

## ⚠️ Важные моменты

1. **Множественный выбор обязателен** - для лучшей работы алгоритма выбирайте несколько групп/целей
2. **Чем больше данных, тем лучше** - минимум 3-4 видео на каждую комбинацию
3. **Fallback работает автоматически** - если нет точного совпадения, система найдет похожее
4. **Логи в консоли** - все операции логируются, проверяйте консоль браузера и сервера
