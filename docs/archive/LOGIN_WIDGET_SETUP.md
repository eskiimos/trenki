# 🔐 Telegram Login Widget - Инструкция

## ✅ Что сделано:

1. ✅ Создана страница `/login` с официальной кнопкой Telegram
2. ✅ API `/api/auth/telegram-widget` для проверки подписи
3. ✅ Автоматическое сохранение пользователя в БД
4. ✅ Редирект на онбординг или главную страницу

## 🔧 ОБЯЗАТЕЛЬНО! Настройка домена в BotFather

**Без этого шага кнопка не будет работать!**

### Шаг 1: Открой @BotFather в Telegram

### Шаг 2: Отправь команду:
```
/setdomain
```

### Шаг 3: Выбери бота:
```
@trenkibot
```

### Шаг 4: Отправь домен:
```
trenki.vercel.app
```

### Шаг 5: BotFather подтвердит:
```
✅ Success! Domain trenki.vercel.app has been set for @trenkiapp_bot
```

## 🧪 Тестирование

После деплоя (2-3 минуты):

1. Открой https://trenki.vercel.app/login
2. Нажми синюю кнопку **"Log in with Telegram"**
3. Откроется popup окно с OAuth Telegram
4. Авторизуйся в Telegram
5. Готово! Ты будешь автоматически залогинен ✅

## ❌ Если видишь ошибку "Bot domain invalid"

Это значит, что домен не настроен в BotFather. Повтори шаги выше!

## 🎯 Как это работает:

1. Пользователь нажимает кнопку
2. Telegram показывает OAuth popup
3. Пользователь подтверждает
4. Telegram отправляет данные с подписью на страницу
5. JavaScript вызывает `/api/auth/telegram-widget`
6. Сервер проверяет подпись (безопасность!)
7. Сохраняет пользователя в БД
8. Возвращает данные
9. Клиент сохраняет в localStorage и редиректит
