# Автоматическое получение метаданных видео из Kinescope

## Как это работает

Когда вы вставляете URL видео Kinescope в форму добавления/редактирования видео, появляется кнопка **"🔄 Получить данные"**.

При нажатии на неё автоматически загружаются:
- ⏱️ **Длительность видео** (в секундах)
- 🖼️ **Превью/постер** (если есть в Kinescope)
- 📝 **Название видео** (если есть в Kinescope)
- 📄 **Описание** (если есть в Kinescope)

## Настройка

### 1. Получите API ключ Kinescope

1. Зайдите в [личный кабинет Kinescope](https://app.kinescope.io/)
2. Перейдите в **Настройки** → **API**
3. Создайте новый API ключ или скопируйте существующий

### 2. Добавьте ключ в .env.local

```bash
KINESCOPE_API_KEY="ваш_api_ключ_здесь"
```

### 3. Перезапустите dev-сервер

```bash
npm run dev
```

## Использование

1. Откройте `/admin/videos`
2. Нажмите "Добавить видео" или "Редактировать" существующее
3. Вставьте URL видео Kinescope (например: `https://kinescope.io/abc123/video456`)
4. Нажмите **"🔄 Получить данные"**
5. Данные автоматически заполнятся в форме!

## Формат URL Kinescope

Поддерживаются следующие форматы:
- `https://kinescope.io/{projectId}/{videoId}`
- `https://kinescope.io/{videoId}`

## Примечание

Если API ключ не настроен, кнопка "Получить данные" будет показывать ошибку с напоминанием о необходимости добавить ключ в `.env.local`.
