### 2. Показан конкретный прирост характеристик

Теперь админ видит **точные значения прироста** для каждой характеристики:

```
📈 Прирост за один модуль:
💪 Сила        +0.23 ⭐
⚡ Скорость     +0.08

* Пример для пользователя с характеристикой 70/100
```

**Легенда:**
- ⭐ — основная характеристика (множитель 1.5)
- Без ⭐ — дополнительная характеристика (множитель 0.5 или 1.0)

### 3. Формула расчёта прироста

```javascript
прирост = base_gain * ((100 - current_value) / 100) * multiplier
```

**Где:**
- `base_gain` = 0.5 (базовый прирост за модуль)
- `current_value` = текущее значение характеристики (0-100)
- `multiplier` = 1.5 (основная), 1.0 (обычная) или 0.5 (дополнительная)

**Пример расчёта для "Мощность" (характеристика 70/100):**
- Сила (основная): `0.5 * ((100-70)/100) * 1.5 = 0.225 ≈ 0.23` ⭐
- Скорость (дополнительная): `0.5 * ((100-70)/100) * 0.5 = 0.075 ≈ 0.08`
