## 🎯 Как теперь работает система:

### 1. Загрузка видео (одним махом!)
1. Открой http://localhost:3001/admin/videos
2. Нажми "+ Добавить видео"
3. Заполни **ВСЕ СРАЗУ**:
   - Основные данные (название, URL, превью)
   - Категория и сложность
   - **НОВОЕ!** Параметры для алгоритма:
     - Тип модуля (Разминка/ОФП/Техника/Заминка)
     - Тип нагрузки (Скорость/Мощность/Сила и т.д.)
     - Группа мышц (Все тело/Низ тела и т.д.)
     - Сложность для алгоритма (Новичок/Любитель/Продвинутый/Профи)
     - RPE диапазон (от X до Y)
4. Нажми "Добавить видео"
5. ✅ ГОТОВО! Видео уже готово для использования алгоритмом!

### 2. Алгоритм подбирает видео
Теперь алгоритм в `/api/training/generate` будет:
1. Определять статус пользователя (RECOVERY/DEVELOPMENT/PEAK)
2. Искать видео НАПРЯМУЮ из таблицы `Video`:
   ```sql
   SELECT * FROM videos
   WHERE типМодуля = 'Разминка'
     AND типНагрузки = 'Динамическая растяжка'
     AND группаМышц = 'Все тело'
     AND сложность = 'Новичок'
     AND rpeМин >= 3 AND rpeМакс <= 5
   ```
3. Формировать тренировку из 4 видео (Разминка + ОФП + Техника + Заминка)
