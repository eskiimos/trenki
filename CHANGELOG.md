# Changelog

Все важные изменения в проекте документируются в этом файле.

## [Unreleased]

### Added 🎉
- **🔐 Вход через Telegram** - официальный Telegram Login Widget
  - Безопасная авторизация в один клик
  - Проверка подписи от Telegram
  - Автоматическое создание пользователя
  - Страница `/login` с красивым UI
  - Компонент `TelegramLogin` для виджета
  - API endpoint `/api/auth/telegram`
  - Перенаправление на заполнение профиля
- **Система авторизации с запоминанием пользователя** - больше не нужно логиниться каждый раз
  - Автологин на 30 дней
  - Сохранение в localStorage
  - Уникальный ID устройства
  - Кнопка "Выйти" в профиле
- **Централизованная библиотека авторизации** (`src/lib/auth.ts`)
  - `saveAuth()` - сохранить авторизацию
  - `getAuth()` - получить данные пользователя
  - `clearAuth()` - выйти
  - `isAuthenticated()` - проверить статус
  - `getTelegramId()` - получить ID
  - `getUserData()` - полные данные
- **Документация системы авторизации**
  - `AUTH_SYSTEM.md` - подробная техническая документация
  - `AUTH_QUICK_START.md` - краткая инструкция для пользователей
  - `DEV_MODE.md` - режим разработки
- **Улучшенный хук useTelegram** - интеграция с системой авторизации
- **Логирование последнего входа** - отслеживание активности пользователя
- **Dev-режим для разработки** - автоматический тестовый пользователь

### Changed 🔄
- **OnboardingWrapper** - проверяет авторизацию перед показом онбординга
- **Onboarding** - сохраняет данные авторизации после регистрации
- **Страница профиля** - добавлена кнопка выхода
- **useTelegram** - теперь использует централизованную систему авторизации

### Fixed 🐛
- Исправлено зависание страницы профиля при загрузке
- Улучшена логика useEffect в странице профиля
- Добавлен таймаут 10 секунд для запросов профиля
- Улучшено логирование в API эндпоинтах

## [2025-10-16] - Исправление онбординга

### Fixed 🐛
- Исправлена проблема "No Telegram ID found" в dev-режиме
- Добавлена поддержка тестового пользователя для локальной разработки

### Added 🎉
- Dev-режим с автоматическим созданием тестового пользователя
- Подробные логи для отладки загрузки профиля

## [2025-10-15] - Начальная версия

## Формат

Используется формат [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).

- **Added** 🎉 - новые функции
- **Changed** 🔄 - изменения существующего функционала
- **Deprecated** ⚠️ - функции, которые будут удалены
- **Removed** 🗑️ - удалённые функции
- **Fixed** 🐛 - исправления багов
- **Security** 🔒 - исправления уязвимостей
