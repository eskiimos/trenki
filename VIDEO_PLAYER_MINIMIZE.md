# Функция сворачивания видеоплеера

## Что реализовано

Добавлена возможность скрывать видеоплеер, кликнув по свободной области страницы видео, для удобного доступа к описанию и комментариям.

## Как работает

### 1. Скрытие плеера
- Пользователь кликает по **свободной области** вне плеера
- Плеер плавно сворачивается вверх (анимация 300ms)
- Видео продолжает воспроизводиться в фоне

### 2. Мини-контроллер
Когда плеер свёрнут, появляется компактная панель с:
- **Превью видео** (64x48px) - миниатюра текущего видео
- **Название видео** - с обрезкой длинных названий
- **Кнопка Play/Pause** - управление без разворачивания
- **Индикатор "Развернуть"** - зелёная стрелка вниз с текстом

### 3. Восстановление плеера
Клик по мини-контроллеру разворачивает плеер обратно

## Технические детали

### Состояние
```typescript
const [isPlayerMinimized, setIsPlayerMinimized] = useState(false);
const playerContainerRef = useRef<HTMLDivElement>(null);
```

### Обработчик клика
```typescript
const handleBackdropClick = (e: React.MouseEvent<HTMLDivElement>) => {
  // Клик только по backdrop, не по дочерним элементам
  if (e.target === e.currentTarget) {
    setIsPlayerMinimized(prev => !prev);
  }
};
```

### Структура компонентов

```tsx
{/* Wrapper с обработчиком клика */}
<div onClick={handleBackdropClick}>
  {/* Контейнер плеера */}
  <div className={isPlayerMinimized ? 'h-0 overflow-hidden' : ''}>
    {/* Сам плеер */}
    <div onClick={(e) => e.stopPropagation()}>
      <video />
      {/* Контролы */}
    </div>
  </div>
</div>

{/* Мини-контроллер когда свёрнут */}
{isPlayerMinimized && (
  <div onClick={() => setIsPlayerMinimized(false)}>
    <Image /> {/* Превью */}
    <button /> {/* Play/Pause */}
    <svg /> {/* Стрелка вниз */}
  </div>
)}
```

### CSS классы

**Анимация сворачивания:**
```typescript
className={`
  transition-all duration-300 
  ${isPlayerMinimized && !isLandscape ? 'h-0 overflow-hidden' : ''}
`}
```

**Мини-контроллер:**
```typescript
className="sticky top-0 z-40 bg-[#0A0E1A] border-b border-[#A1FF4A]/20 
           px-4 py-3 flex items-center justify-between 
           cursor-pointer hover:bg-[#0A0E1A]/80 transition-all group"
```

## Особенности реализации

### 1. Защита от случайных кликов
- `e.stopPropagation()` на плеере - клики по плеюру не сворачивают
- `e.target === e.currentTarget` - только клик по самому backdrop
- Контролы плеера не вызывают сворачивание

### 2. Ландшафтный режим
```typescript
{isPlayerMinimized && !isLandscape && (...)}
```
В ландшафтном режиме (fullscreen) сворачивание не работает

### 3. Сохранение воспроизведения
Видео продолжает играть в фоне:
- State `isPlaying` не меняется при сворачивании
- Можно управлять через мини-кнопку Play/Pause
- Прогресс продолжает отслеживаться

### 4. Sticky позиционирование
Мини-контроллер использует `sticky top-0`:
- Остаётся видимым при скролле
- Всегда доступен для разворачивания
- z-index: 40 для видимости поверх контента

## Визуальный дизайн

### Цветовая схема
- **Фон**: `#0A0E1A` (тёмный синий)
- **Акцент**: `#A1FF4A` (неоновый зелёный)
- **Бордер**: `#A1FF4A/20` (20% opacity)
- **Hover**: `#0A0E1A/80` (80% opacity)

### Типографика
```tsx
<h3 className="text-white text-sm font-medium truncate">
  {videoData?.title}
</h3>
<p className="text-[#A1FF4A]/70 text-xs font-medium">
  Нажмите чтобы развернуть ↓
</p>
<span className="text-[10px] text-[#A1FF4A]/60 uppercase font-bold tracking-wider">
  Развернуть
</span>
```

### Анимации
- Сворачивание плеера: `transition-all duration-300`
- Hover эффект: `hover:bg-[#0A0E1A]/80`
- Стрелка при hover: `group-hover:translate-y-0.5`
- Кнопка Play/Pause: `hover:bg-[#A1FF4A]/20`

## UX улучшения

### 1. Индикатор действия
Зелёная стрелка вниз с текстом "Развернуть" - понятная визуальная подсказка

### 2. Превью видео
Миниатюра помогает не потерять контекст какое видео сейчас играет

### 3. Встроенное управление
Кнопка Play/Pause в мини-контроллере - не нужно разворачивать для паузы

### 4. Hover состояния
Все интерактивные элементы имеют hover эффекты для feedback

## Тестирование

### Сценарии для проверки

**1. Базовое сворачивание:**
- Открыть страницу видео
- Кликнуть по чёрной области вокруг плеера
- Плеер должен плавно свернуться
- Появляется мини-контроллер

**2. Восстановление:**
- При свёрнутом плеере кликнуть по мини-контроллеру
- Плеер разворачивается обратно
- Видео продолжает играть с того же места

**3. Управление в свёрнутом состоянии:**
- Свернуть плеер
- Кликнуть по кнопке Play/Pause в мини-контроллере
- Видео ставится на паузу/продолжает играть
- Плеер остаётся свёрнутым

**4. Защита от случайных кликов:**
- Кликнуть по контролам плеера
- Плеер НЕ должен свернуться
- Кликнуть по превью видео в свёрнутом состоянии
- Плеер разворачивается

**5. Ландшафтный режим:**
- Перевернуть устройство в landscape
- Функция сворачивания должна быть отключена
- Мини-контроллер не появляется

**6. Sticky behaviour:**
- Свернуть плеер
- Проскроллить страницу вниз
- Мини-контроллер должен оставаться вверху экрана
