# Вход через Telegram бота

## 🔐 Новый сценарий авторизации

Реализован упрощенный и безопасный вход через Telegram бота с автоматической генерацией email.

## 📱 Как это работает

### Для пользователя:

1. **Открывает страницу `/login`** в веб-приложении
2. **Нажимает кнопку "Вход через Telegram"**
3. **Открывается бот** @trenkiapp_bot с ссылкой `/start {token}`
4. **Бот автоматически:**
   - Создает или находит пользователя
   - Генерирует email в формате `{telegram_id}@t.me`
   - Подтверждает вход
5. **Пользователь возвращается** в приложение - он уже авторизован!

## 📧 Автоматический Email

Каждому пользователю при первом входе через Telegram присваивается email в формате:

```
{telegram_id}@t.me
```

**Примеры:**
- Telegram ID: `123456789` → Email: `123456789@t.me`
- Telegram ID: `987654321` → Email: `987654321@t.me`

**Особенности:**
- ✅ Автоматически верифицирован (`emailVerified: true`)
- ✅ Уникален для каждого пользователя
- ✅ Не требует подтверждения кода
- ✅ Используется только для идентификации

## 🎯 Преимущества

✅ **Простота** - один клик для входа  
✅ **Безопасность** - через официальный Telegram  
✅ **Автоматизация** - email генерируется сам  
✅ **Нет регистрации** - создается при первом входе  
✅ **Кроссплатформенность** - работает везде  
✅ **Нет паролей** - не нужно запоминать
