## Что протестировать

### 1. Регистрация нового пользователя

**Шаги:**
1. Открыть приложение в режиме разработки
2. Пройти онбординг
3. На шаге ввода данных:
   - Указать дату рождения (вместо возраста)
   - Выбрать пол
4. Завершить регистрацию

**Ожидаемый результат:**
- Дата рождения сохранена
- `ageGroup` автоматически определена
- Возраст вычисляется корректно

**Проверка в консоли:**
```typescript
// В браузере
fetch('/api/profile?telegramId=YOUR_ID')
  .then(r => r.json())
  .then(console.log)

// Ожидаемый ответ:
{
  profile: {
    birthDate: "1999-03-20T00:00:00.000Z",
    ageGroup: "YOUNG_ADULT",
    // age НЕ сохраняется в БД, вычисляется при запросе
  }
}
```

### 2. Редактирование профиля

**Шаги:**
1. Перейти в Профиль → Редактировать
2. Изменить дату рождения
3. Сохранить

**Ожидаемый результат:**
- Новая дата рождения сохранена
- `ageGroup` пересчитана автоматически
- Возраст обновился

**Проверка:**
```bash
# Проверить через check-users.ts
npx ts-node check-users.ts

# Вывод должен содержать:
# Возраст: 25 лет (ДР: 1999-03-20)
# Возрастная группа: YOUNG_ADULT
```

### 3. Проверка UI

**Date Picker:**
- Поле показывает "ДАТА РОЖДЕНИЯ" (не "ВОЗРАСТ")
- Type: date (календарь)
- Max: сегодняшняя дата
- При выборе даты → автоматически определяется группа

**Валидация:**
```typescript
// Попробовать ввести:
- Дату в будущем ❌ (должна блокироваться)
- Возраст < 7 лет ❌ (должна отклоняться API)
- Возраст > 100 лет ❌ (должна отклоняться API)
- Сегодняшнюю дату - 10 лет ✅ (CHILD)
- Сегодняшнюю дату - 15 лет ✅ (TEEN)
- Сегодняшнюю дату - 25 лет ✅ (YOUNG_ADULT)
- Сегодняшнюю дату - 40 лет ✅ (ADULT)
```

### 4. Проверка алгоритма тренировок

**Важно:** Алгоритм 2.0 использует `ageGroup` для подбора видео

```bash
# Создать тренировку
POST /api/training/generate-v3
{
  "trainingGoal": "POWERFUL_SHOT"
}
```

**Проверка:**
1. Тренировка генерируется с учётом `profile.ageGroup`
2. Видео фильтруются по `ageGroups` массиву
3. Подходят только видео для возрастной группы пользователя

**Сценарии:**
```typescript
// CHILD (7-10): должны подходить детские видео
// TEEN (11-17): подростковые + общие
// YOUNG_ADULT (18-34): взрослые среднего возраста
// ADULT (35+): видео для старшей группы
```

### 5. Проверка миграции существующих данных

**Если есть старые пользователи с `age`:**

```sql
-- Проверить пользователей без birthDate
SELECT 
  u.id,
  u."firstName",
  u."lastName",
  p."birthDate",
  p."ageGroup"
FROM users u
LEFT JOIN profiles p ON p."userId" = u.id
WHERE p."birthDate" IS NULL;
```

**Если нашлись:**
```typescript
// Создать скрипт миграции
// Пример: если возраст был 25, установить birthDate ~ 1999 год

import prisma from './src/lib/prisma';

async function migrateAgeData() {
  const profiles = await prisma.profile.findMany({
    where: { birthDate: null }
  });
  
  for (const profile of profiles) {
    // Примерная дата рождения
    const currentYear = new Date().getFullYear();
    const birthYear = currentYear - 25; // или другая логика
    const birthDate = new Date(`${birthYear}-06-15`);
    
    const { ageGroup } = calculateAgeData(birthDate);
    
    await prisma.profile.update({
      where: { id: profile.id },
      data: { birthDate, ageGroup }
    });
  }
}
```

## Тест-кейсы

### ✅ Успешные сценарии

| Тест | Input | Expected Output |
|------|-------|----------------|
| Регистрация 10 лет | `2014-01-01` | `ageGroup: CHILD` |
| Регистрация 15 лет | `2009-06-15` | `ageGroup: TEEN` |
| Регистрация 25 лет | `1999-03-20` | `ageGroup: YOUNG_ADULT` |
| Регистрация 40 лет | `1984-12-10` | `ageGroup: ADULT` |
| Редактирование даты | Изменить на `2000-01-01` | Группа пересчитана |
| День рождения сегодня | Возраст не уменьшается | Корректный возраст |
| День рождения завтра | Возраст уменьшен на 1 | Возраст еще не наступил |

### ❌ Ошибочные сценарии

| Тест | Input | Expected Error |
|------|-------|---------------|
| Будущая дата | `2030-01-01` | `Invalid birth date` |
| Младше 7 лет | `2020-01-01` | `Invalid birth date` |
| Старше 100 лет | `1900-01-01` | `Invalid birth date` |
| Невалидный формат | `not-a-date` | Validation error |
