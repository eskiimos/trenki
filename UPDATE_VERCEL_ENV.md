# 🔄 Обновление переменных окружения Vercel

## ⚠️ КРИТИЧНО - Это решит проблему редиректа на старого бота!

Когда вы пытаетесь авторизоваться через Telegram, приложение все еще показывает старого бота (@trenkibot) потому что **Vercel использует переменные окружения со старыми значениями**.

## 🔧 Как обновить на Vercel:

### Шаг 1: Войти на Vercel
1. Откройте https://vercel.com/dashboard
2. Войдите в свой аккаунт

### Шаг 2: Выбрать проект
1. В списке проектов найдите **trenki**
2. Нажмите на него

### Шаг 3: Перейти к переменным окружения
1. Нажмите на **Settings** (в меню сверху)
2. Выберите **Environment Variables** (слева в сайдбаре)

### Шаг 4: Обновить BOT_TOKEN

Найдите переменную **BOT_TOKEN**:
- **Старое значение:** `8124848980:AAE6ZD6wkWPsCmEKNq2a68gHVo58p4D7Jp4`
- **Новое значение:** `8405285944:AAHmnub0gtc4tKhPdU8njuIf4cgga8AczC8`

Действия:
1. Нажмите на строку с `BOT_TOKEN`
2. Нажмите иконку редактирования (карандаш)
3. Измените значение на новый токен
4. Убедитесь что переменная применяется ко всем окружениям:
   - ✓ Production
   - ✓ Preview  
   - ✓ Development
5. Нажмите **Save**

### Шаг 5: Обновить NEXT_PUBLIC_BOT_USERNAME

Найдите переменную **NEXT_PUBLIC_BOT_USERNAME**:
- **Старое значение:** `trenkibot`
- **Новое значение:** `trenkiapp_bot`

Действия:
1. Нажмите на строку с `NEXT_PUBLIC_BOT_USERNAME`
2. Нажмите иконку редактирования
3. Измените значение на `trenkiapp_bot`
4. Убедитесь что применяется ко всем окружениям
5. Нажмите **Save**

### Шаг 6: Проверить другие переменные

Убедитесь что есть и правильны:
- `WEB_APP_URL` = `https://trenki.vercel.app` (или ваш домен)
- Остальные переменные не должны содержать старый токен

## 🚀 Шаг 7: Автоматическое переразворачивание

После сохранения переменных:
1. Vercel **автоматически перезапустит сборку**
2. Приложение обновится на production
3. Новое развертывание будет в списке в разделе **Deployments**

**Это займет примерно 1-2 минуты**

## ✅ Проверка

После обновления:
1. Перейдите на https://trenki.vercel.app (или ваш домен)
2. Нажмите "Вход через Telegram"
3. Должна открыться ссылка на **@trenkiapp_bot** вместо @trenkibot
4. Авторизация должна работать корректно

## 🔍 Если не работает

Если после обновления Vercel переменных авторизация все еще не работает:

1. **Очистите кэш браузера:**
   - Ctrl+Shift+Delete (Windows) или Cmd+Shift+Delete (Mac)
   - Удалите кэш для trenki.vercel.app

2. **Проверьте что переменные сохранились:**
   - Вернитесь на страницу Environment Variables
   - Убедитесь что новые значения там

3. **Проверьте Deployments:**
   - Перейдите на вкладку **Deployments**
   - Должно быть новое развертывание с обновленными переменными

4. **Проверьте Git (для убедства):**
   - Переменные окружения на Vercel перезаписывают локальные .env файлы
   - Поэтому нет нужды пушить какие-то дополнительные изменения
