# Технологический стек проекта Trenki

## Фронтенд

### Ядро
- **Next.js 15.5.2** - React фреймворк с App Router для серверного рендеринга и маршрутизации
- **React 19** - Библиотека для построения пользовательских интерфейсов
- **TypeScript** - Типизированный JavaScript для повышения надежности кода

### Стилизация
- **Tailwind CSS 3.4.17** - Утилитарный CSS фреймворк для быстрой разработки интерфейсов
- **PostCSS** - Инструмент для трансформации CSS

### Компоненты интерфейса и иконки
- **Lucide React** - Набор иконок для React приложений

## Бэкенд

### База данных и ORM
- **Prisma 6.16.1** - ORM для работы с базой данных
- **PostgreSQL** - Реляционная база данных (через Prisma Accelerate)
- **Prisma Accelerate** - Сервис для ускорения запросов к базе данных

### API
- **Next.js API Routes** - Серверные эндпоинты внутри Next.js приложения
- **RESTful API** - Архитектурный стиль для построения API

## Внешние сервисы

### Хостинг видео
- **Kinescope API** - Платформа для хостинга и стриминга видео
  - Автоматическое получение метаданных видео
  - Встроенный видеоплеер через iframe
  - Поддержка различных форматов и качества

### Интеграция с Telegram
- **Telegram Web App API** - Интеграция с Telegram Mini Apps
  - Аутентификация через Telegram
  - Доступ к данным пользователя Telegram
  - Нативные возможности Telegram WebApp

## Инструменты разработки

### Качество кода
- **ESLint** - Линтер для поддержания качества кода
- **TypeScript ESLint** - Правила ESLint для TypeScript

### Контроль версий
- **Git** - Система контроля версий
- **GitHub** - Хостинг репозитория

## Структура проекта

### Ключевые функции
1. **Каталог видео** - Каталог тренировочных видео с фильтрацией
2. **Шортсы (формат TikTok)** - Вертикальные короткие видео с свайпами
3. **Админ-панель** - Панель управления контентом
4. **Профили тренеров** - Профили тренеров с информацией

### Модели базы данных
- **User** - Пользователи приложения
- **Profile** - Профили пользователей
- **Trainer** - Информация о тренерах
- **Video** - Полноформатные видео тренировок
- **Short** - Короткие видео (формат TikTok)
- **FavoriteVideo** - Избранные видео пользователей

## Архитектура

### Паттерн
- **Монолитная архитектура** - Единое Next.js приложение с серверными и клиентскими компонентами
- **SSR + CSR** - Комбинация серверного и клиентского рендеринга

### API эндпоинты
```
/api/videos          - CRUD операции с видео
/api/videos/[id]     - Операции с конкретным видео
/api/shorts          - CRUD операции с shorts
/api/shorts/[id]     - Операции с конкретным short
/api/trainers        - Получение списка тренеров
/api/user/status     - Статус пользователя
/api/kinescope/metadata - Получение метаданных из Kinescope
/api/upload          - Загрузка файлов
```
