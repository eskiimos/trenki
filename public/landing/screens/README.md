# Скриншоты экранов для лендинга

Сюда кладём реальные скриншоты экранов приложения. Компонент `PhoneShot`
(`src/app/landing/page.tsx`) подставляет их в телефон-фреймы по имени файла.
Если файла нет — показывается пустой слот с подписью экрана.

## Файлы (WebP)

| Файл             | Экран в лендинге                          |
|------------------|-------------------------------------------|
| `catalog.webp`   | Каталог (он же в герое, первый телефон)   |
| `assessment.webp`| ИИ-тренер (выбор цели/состояния)          |
| `calendar.webp`  | Календарь / микроцикл                     |
| `profile.webp`   | Профиль / прогресс                        |
| `workout.webp`   | Тренировка (модули)                       |

## Как обновить
1. Кладём вертикальные PNG-скриншоты телефона (тёмная тема, фон `#060919`,
   без системной шторки — фрейм рисует свою «чёлку»).
2. Конвертируем в WebP (q82) — например через `sharp`:
   `sharp(src).webp({ quality: 82 }).toFile(dst)`.
3. Кладём `*.webp` сюда (имена из таблицы), PNG в репозитории не храним.

Фрейм обрезает по `object-fit: cover`, выравнивание — по верху.
