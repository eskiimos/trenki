# Скриншоты экранов для лендинга

Сюда кладём реальные скриншоты экранов приложения. Компонент `PhoneShot`
(`src/app/landing/page.tsx`) подставляет их в телефон-фреймы по имени файла.
Если файла нет — показывается пустой слот с подписью экрана.

## Ожидаемые файлы (PNG)

| Файл            | Экран в лендинге                          |
|-----------------|-------------------------------------------|
| `catalog.png`   | Каталог (он же в герое, первый телефон)   |
| `assessment.png`| ИИ-тренер (выбор цели/состояния)          |
| `calendar.png`  | Календарь / микроцикл                     |
| `profile.png`   | Профиль / прогресс                        |
| `workout.png`   | Тренировка (модули)                       |

## Требования
- Формат: **PNG**, вертикальные скриншоты телефона (например 1080×2340 или
  390×844 @2x). Фрейм обрезает по `object-fit: cover`, выравнивание — по верху.
- Тёмная тема приложения (фон `#060919`), чтобы совпадало с фреймом.
- Без системной шторки/часов сверху — фрейм рисует свою «чёлку».
