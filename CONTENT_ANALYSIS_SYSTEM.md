# 📊 Система анализа контента /admin/content-check

## 🎯 Что сделано

Создана умная система анализа базы видео, которая подсказывает **какие видео нужно загружать в первую очередь** для оптимальной работы алгоритма генерации тренировок.

## 🔧 Компоненты

### 1. API Endpoint: `/api/admin/content-check`

**Файл:** `src/app/api/admin/content-check/route.ts`

**Что делает:**
- Анализирует всю базу опубликованных видео
- Находит пробелы в комбинациях `moduleType + loadType + muscleGroup` для разных статусов
- Рассчитывает приоритеты на основе важности модуля:
  - 🔥 **Приоритет 10** (КРИТИЧНО): FITNESS - стержневой модуль, без него тренировка невозможна
  - ⚠️ **Приоритет 9** (ВАЖНО): WARMUP/COOLDOWN - обязательные части тренировки
  - ⚠️ **Приоритет 7-8** (ВАЖНО): Разнообразие мышечных групп
  - 💡 **Приоритет 5-6** (ЖЕЛАТЕЛЬНО): TECHNIQUE - добавляет специализацию

**Логика приоритетов:**

1. **FITNESS (стержневой модуль):**
   - Для каждого статуса (RECOVERY/DEVELOPMENT/PEAK) проверяет типы нагрузки
   - Критично если < 2 видео на тип нагрузки
   - Важно покрытие всех 9 мышечных групп

2. **WARMUP:**
   - Критично наличие разминки FULL_BODY для каждого статуса
   - Важно разнообразие других мышечных групп

3. **COOLDOWN:**
   - Критично наличие заминки FULL_BODY
   - Важно разнообразие других мышечных групп

4. **TECHNIQUE:**
   - Проверяет совместимость с типами нагрузки FITNESS
   - Желательно иметь разнообразие

### 2. UI Страница: `/admin/content-check`

**Файл:** `src/app/admin/content-check/page.tsx`

**Что показывает:**

1. **Статистика:**
   - Всего видео в базе
   - Количество критичных/важных/желательных пробелов

2. **Распределение по модулям:**
   - FITNESS (стержневой) - сколько видео
   - WARMUP - сколько видео
   - COOLDOWN - сколько видео  
   - TECHNIQUE - сколько видео

3. **Распределение по статусам:**
   - 🟢 RECOVERY (восстановление)
   - 🟡 DEVELOPMENT (развитие)
   - 🔴 PEAK (пик)

4. **Топ-15 приоритетов:**
   - Цветные карточки с градиентом по важности
   - Подробное описание что нужно и почему
   - Прогресс-бар (сколько/сколько нужно)
   - Приоритет от 1 до 10

5. **Информация:**
   - Объяснение как работает система приоритетов
   - Что означает каждый уровень важности

## 🚀 Как использовать результаты

1. Откройте `/admin/content-check`
2. Посмотрите топ приоритетов
3. Начинайте загружать видео с **красными карточками** (критично)
4. Затем переходите к **оранжевым** (важно)
5. В последнюю очередь - **синие** (желательно)

## 💡 Примеры критичных пробелов

1. **FITNESS - MOBILITY для RECOVERY:**
   - Нет ни одного видео
   - Нужно минимум 3 видео
   - Без этого невозможна тренировка на восстановление

2. **WARMUP - DYNAMIC_STRETCH для FULL_BODY:**
   - Нет разминки для всего тела
   - Нужно минимум 2 видео
   - Без этого тренировки будут неполными

3. **COOLDOWN - STATIC_STRETCH для FULL_BODY:**
   - Нет заминки для всего тела
   - Нужно минимум 2 видео
   - Без этого тренировки не завершаются правильно

## ⚙️ Технические детали

- Использует те же правила совместимости что и алгоритм генерации тренировок
- Основан на документе "Треньки" (с) - стержневой принцип
- Учитывает все enum поля: ModuleType, LoadType, MuscleGroup, TrainingGoal
- Проверяет покрытие всех возможных комбинаций
- Сортирует по приоритету от большего к меньшему
