# 📅 Интеграция с календарём устройства

## ✅ Что реализовано

### 1. API Endpoint `/api/calendar/ics`
- **Метод**: POST
- **Формат**: Генерирует .ICS файл (iCalendar стандарт)
- **Совместимость**: iOS, Android, Windows, macOS
- **Данные**: Автоматически получает данные видео и тренера из БД

**Параметры запроса:**
```json
{
  "videoId": "video-id",
  "date": "2026-01-16T18:00:00.000Z"
}
```

**Что включено в .ICS файл:**
- 📋 Название тренировки (с emoji 🏋️)
- 👤 Имя тренера
- ⏱ Длительность тренировки
- 📍 Локация: Онлайн
- 🔗 Ссылка на открытие в приложении
- ⏰ Напоминания за 30 и 10 минут

### 2. Обновлён ScheduleModal
- ✅ Добавлена кнопка "Добавить в календарь устройства"
- ✅ Кнопка появляется после успешного сохранения в календарь приложения
- ✅ Поддержка Web Share API для мобильных устройств
- ✅ Fallback на скачивание для desktop
- ✅ Обработка нескольких дат (если выбрано несколько тренировок)

## 🎯 Как это работает

### Для пользователя:

1. **Выбирает дату(ы) и время** в календаре приложения
2. **Нажимает "СОХРАНИТЬ"** → тренировка сохраняется в БД
3. **Видит экран успеха** с превью видео
4. **Нажимает "ДОБАВИТЬ В КАЛЕНДАРЬ УСТРОЙСТВА"**

**На iOS:**
- Открывается системный Share Sheet
- Пользователь выбирает "Добавить в Календарь"
- Событие автоматически добавляется в календарь iOS

**На Android:**
- Открывается системный Share Sheet
- Пользователь выбирает Google Calendar или другое приложение
- Событие добавляется в выбранный календарь

**На Desktop:**
- Скачивается .ICS файл
- Пользователь открывает файл
- Календарь (Outlook, iCal, Google Calendar) предлагает добавить событие

## 🔧 Технические детали

### Формат iCalendar (.ICS)
```
BEGIN:VCALENDAR
VERSION:2.0
PRODID:-//Trenki//Workout Calendar//RU
METHOD:PUBLISH
BEGIN:VEVENT
UID:workout-{videoId}-{timestamp}@trenki.app
DTSTART:20260116T180000Z
DTEND:20260116T184500Z
SUMMARY:🏋️ Название тренировки
DESCRIPTION:Тренировка с Имя Тренера\nДлительность: 45 мин
LOCATION:Онлайн
BEGIN:VALARM
TRIGGER:-PT30M
ACTION:DISPLAY
DESCRIPTION:Через 30 минут начнётся тренировка!
END:VALARM
END:VEVENT
END:VCALENDAR
```

### Web Share API
Используется для нативного опыта на мобильных:
```typescript
if (navigator.share && /iPhone|iPad|iPod|Android/i.test(navigator.userAgent)) {
  await navigator.share({
    files: [file],
    title: '🏋️ Тренировка',
    text: 'Добавить в календарь'
  });
}
```

### Fallback для Desktop
Если Web Share API не поддерживается:
```typescript
const a = document.createElement('a');
a.href = url;
a.download = filename;
a.click();
```

## ⚡ Преимущества

✅ **Двойная система:**
- Тренировка сохраняется в приложении (БД) для уведомлений
- Дополнительно добавляется в календарь устройства

✅ **Универсальность:**
- Работает на всех платформах
- Нативный опыт на мобильных
- Стандартный формат .ICS

✅ **Удобство:**
- Напоминания в обоих календарях
- Синхронизация с другими устройствами пользователя
- Интеграция с существующими событиями

✅ **Не требует разрешений:**
- Нет запроса доступа к календарю
- Пользователь сам контролирует добавление
