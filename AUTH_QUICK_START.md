# 🔐 Быстрый старт: Авторизация

## Что изменилось?

Теперь приложение **запоминает пользователя** и не требует повторного входа!

## Как это работает?

### 1️⃣ Первый вход
1. Откройте приложение
2. Пройдите онбординг (3 экрана)
3. Введите данные (имя, фамилия, возраст, пол)
4. ✅ Готово! Вы автоматически залогинены

### 2️⃣ Последующие запуски
- Просто открываете приложение → **сразу попадаете на главную**
- Онбординг больше не показывается
- Ваши данные сохранены на устройстве

### 3️⃣ Выход
Если нужно выйти:
1. Перейдите в **Профиль** (иконка справа внизу)
2. Прокрутите вниз
3. Нажмите **"🚪 Выйти"**
4. При следующем запуске увидите онбординг снова

## Сколько действует авторизация?

**30 дней** с момента последнего входа.

После этого нужно будет пройти онбординг заново.

## Важно знать

- ✅ Работает в браузере (Chrome, Safari, Firefox)
- ✅ Работает в Telegram Mini App
- ✅ Данные сохраняются на устройстве (не на сервере)
- ⚠️ Если очистить кеш браузера → нужно войти заново
- ⚠️ В режиме инкогнито → авторизация не сохраняется

## Для разработчиков

### Очистить данные авторизации

Откройте консоль браузера (F12) и выполните:

```javascript
localStorage.clear();
location.reload();
```

### Посмотреть сохранённые данные

```javascript
console.log(JSON.parse(localStorage.getItem('trenki_auth')));
```

### Изменить срок действия

В файле `src/lib/auth.ts` найдите строку:

```typescript
if (daysSinceLogin > 30) {  // <-- измените число дней
```

## FAQ

**Q: Нужно ли входить каждый раз?**  
A: Нет! После первого входа вы автоматически залогинены на 30 дней.

**Q: Что если я хочу сменить аккаунт?**  
A: Нажмите кнопку "Выйти" в профиле, затем пройдите онбординг с новыми данными.

**Q: Безопасно ли это?**  
A: Для MVP — да. Для production рекомендуем добавить JWT токены и серверную валидацию (см. `AUTH_SYSTEM.md`).

**Q: Работает ли на разных устройствах?**  
A: Да, но авторизация сохраняется **на каждом устройстве отдельно**. На новом устройстве нужно пройти онбординг.

**Q: Что если закрою браузер?**  
A: Авторизация сохраняется! Можете закрывать и открывать браузер сколько угодно.
