# Режим разработки (DEV MODE)

## Проблема
Приложение не работало без Telegram WebApp API, так как не могло получить `telegramId` пользователя.

## Решение
Добавлен режим разработки, который автоматически создаёт тестового пользователя при локальной разработке.

## Что изменено

### 1. `src/hooks/useTelegram.ts`
- Добавлена проверка на `NODE_ENV === 'development'`
- Если Telegram WebApp недоступен, создаётся тестовый пользователь
- ID пользователя сохраняется в `localStorage` для постоянства между перезагрузками
- Тестовый пользователь имеет ID формата `dev_TIMESTAMP`

### 2. `src/lib/dev-user.ts` (НОВЫЙ ФАЙЛ)
- Утилита для автоматического создания dev пользователей в БД
- Проверяет, существует ли пользователь с `telegramId` начинающимся с `dev_`
- Если нет - создаёт пользователя с дефолтным профилем
- Работает только в development режиме

### 3. `src/app/api/training/assessment/route.ts`
- Добавлен вызов `ensureDevUser(userId)` перед обработкой запроса
- Автоматически создаёт пользователя в БД для dev режима

### 4. `src/app/api/training/generate/route.ts`
- Добавлен вызов `ensureDevUser(userId)` перед обработкой запроса
- Автоматически создаёт пользователя в БД для dev режима

### 5. `src/app/training/assessment/page.tsx`
- Добавлено подробное логирование для отладки
- Улучшена обработка ошибок с информативными сообщениями

## Как это работает

1. **Первый запуск в браузере (не в Telegram):**
   - Создаётся уникальный ID на основе `Date.now()` с префиксом `dev_`
   - ID сохраняется в `localStorage` как `dev_telegram_id`
   - Создаётся объект пользователя в памяти
   - При первом API запросе пользователь автоматически создаётся в БД

2. **Последующие запуски:**
   - Используется сохранённый ID из `localStorage`
   - Пользователь остаётся авторизованным
   - БД запросы работают с существующим пользователем

3. **В Telegram Mini App:**
   - Работает как обычно с реальным Telegram ID
   - Dev-режим не активируется

## Тестирование

### Локальная разработка
```bash
npm run dev
```
Откройте http://localhost:3001 в браузере

### Проверка создания пользователя
1. Откройте консоль браузера (F12)
2. Перейдите на страницу `/training/assessment`
3. Заполните форму и нажмите "Вперёд"
4. Проверьте логи:
   - `🔧 DEV MODE: Created new test user ID: dev_XXXXX`
   - `🔧 DEV MODE: Creating new dev user in DB`
   - `✅ DEV MODE: Created user`

### Сброс dev-пользователя
Откройте консоль браузера и выполните:
```javascript
localStorage.removeItem('dev_telegram_id');
location.reload();
```

### Проверка логов
Откройте консоль браузера (F12) и следите за сообщениями:
- `🔧 DEV MODE` - dev режим активирован
- `🎯 Assessment submit` - отправка assessment
- `📤 Sending assessment` - отправка данных
- `📥 Assessment response` - получен ответ
- `✅ Workout generated` - тренировка сгенерирована

## Важно
- Dev-режим работает только при `NODE_ENV === 'development'`
- В production всегда требуется реальный Telegram WebApp
- Тестовый пользователь создаётся автоматически, вмешательство не требуется
- Все dev пользователи имеют telegramId формата `dev_TIMESTAMP`
