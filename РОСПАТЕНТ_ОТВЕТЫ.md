# Ответы для регистрации в Роспатенте

## 6. Область применения и выполняемые функции программой для ЭВМ (до 900 знаков)

Программа "Треньки" - прогрессивное веб-приложение для персональных тренировок хоккеистов. Обеспечивает доступ к каталогу видеоуроков с тренировками от профессиональных тренеров, с возможностью просмотра как полноформатных занятий, так и коротких видео в формате TikTok/Shorts с навигацией свайпами. Включает систему аутентификации через Telegram, личный кабинет пользователя с отслеживанием прогресса и статистики, профили тренеров, функцию избранного, адаптивный дизайн для мобильных устройств. Поддерживает PWA-функциональность: установку на домашний экран, офлайн-режим, push-уведомления. Включает административную панель для управления контентом, интеграцию с Telegram-ботом через webhooks, автоматическую email-верификацию пользователей. Предназначена для спортсменов-хоккеистов, тренеров и любителей хоккея.

**Длина:** 767 знаков (включая пробелы)

## 7. Язык программирования

TypeScript, JavaScript, TSX/JSX, CSS, SQL (Prisma ORM)

---

## 8. Операционные системы

Кроссплатформенное веб-приложение. Работает в веб-браузерах на операционных системах:
- Windows 10 и выше
- macOS 10.15 и выше
- Linux (любой дистрибутив с современным браузером)
- iOS 12 и выше
- Android 8.0 и выше

## 9. Размер программы

**72 МБ** (исходный код без библиотек и зависимостей)

## 10. Требуется отдельный файл

Создайте файл в формате Microsoft Word (.docx) с фрагментом исходного кода.

**Рекомендация:** Включите в документ основные компоненты программы, демонстрирующие уникальность и функциональность:

1. Главная страница приложения (src/app/page.tsx)
2. Компонент видеоплеера (src/components/VideoPlayer.tsx или аналогичный)
3. API endpoint для работы с видео (src/app/api/videos/route.ts)
4. Схема базы данных (prisma/schema.prisma)
5. Компонент аутентификации через Telegram

Файл должен содержать заголовок с названием программы, номера строк кода и комментарии, поясняющие назначение основных функций.

Объем фрагмента: 50-100 страниц будет достаточно для идентификации программы.
