# ✅ Реализация системы хранения тренировок

## Что сделано:

### 1. База данных ✅
- Обновлена модель `WorkoutSession` с новыми полями:
  - `startedAt` - когда начата тренировка
  - `currentVideoIndex` - индекс текущего видео
  - `totalVideos` - общее количество видео
- Создана модель `WorkoutSessionVideo` для связи тренировок с видео
- Добавлены индексы для быстрого поиска

### 2. API Endpoints ✅

#### `/api/training/generate` (обновлен)
- Теперь сохраняет тренировку в БД
- Создает записи `WorkoutSession` и `WorkoutSessionVideo`
- Возвращает реальный ID из базы данных

#### `/api/training/current` (обновлен)
- Возвращает текущую незавершенную тренировку (PENDING или IN_PROGRESS)
- Работает с новой моделью `WorkoutSessionVideo`
- Возвращает прогресс выполнения

#### `/api/training/update` (новый)
- `action: 'start'` - начать видео (обновляет статус на IN_PROGRESS)
- `action: 'complete'` - завершить видео (увеличивает currentVideoIndex)
- `action: 'progress'` - обновить прогресс просмотра
- Автоматически завершает тренировку когда все видео просмотрены

### 3. Компоненты ✅

#### `<WorkoutReminder />` (новый)
- Показывает напоминание о незавершенной тренировке
- Отображает прогресс (X/Y видео, процент)
- Кнопка "Продолжить" ведет к странице тренировки
- Красивая анимация с градиентом 🔥

#### Обновления в `/app/page.tsx`
- Добавлен `<WorkoutReminder />` на главную страницу
- Показывается только если есть незавершенная тренировка

#### Обновления в `/training/workout`
- Поддержка загрузки тренировки по ID из query параметра
- Передает `sessionId` при переходе к видео

#### Обновления в `/video/[id]`
- Получает `sessionId` из URL
- Автоматически отмечает начало видео через `/api/training/update`
- Кнопка "Назад" возвращает к тренировке если `fromWorkout=true`

### 2. Тестовый сценарий

**Шаг 1: Создать тренировку**
1. Открыть `/training/assessment`
2. Заполнить форму оценки
3. Нажать "Сгенерировать тренировку"
4. Проверить что тренировка сохранилась в БД

**Шаг 2: Проверить напоминание**
1. Вернуться на главную страницу `/`
2. Должно появиться оранжевое напоминание 🔥
3. Показан прогресс 0/N видео (0%)

**Шаг 3: Начать тренировку**
1. Нажать "Продолжить" или "Начать"
2. Откроется страница тренировки
3. Нажать "Начать тренировку"
4. Откроется первое видео

**Шаг 4: Проверить отслеживание**
1. Видео должно автоматически отметиться как начатое
2. Статус тренировки изменится на IN_PROGRESS
3. Кнопка "Назад" возвращает к странице тренировки

**Шаг 5: Закрыть и вернуться**
1. Закрыть приложение/вкладку
2. Открыть снова
3. На главной должно быть напоминание с прогрессом
4. Нажать "Продолжить"
5. Должно открыться текущее видео

**Шаг 6: Завершить тренировку**
1. Просмотреть все видео до конца
2. Тренировка автоматически завершится
3. Напоминание исчезнет с главной

## Известные ограничения:

1. **Временное решение:** `/api/training/current` возвращает последнюю незавершенную тренировку. Если пользователь создаст новую, старая будет недоступна. Нужен отдельный endpoint `/api/training/session/{id}` для загрузки конкретной тренировки.

2. **Навигация между видео:** Пока нет кнопки "Следующее видео" в плеере. Пользователь должен возвращаться к странице тренировки и выбирать следующее.

3. **Отслеживание завершения видео:** Пока нет автоматического определения когда видео досмотрено до конца. Нужно добавить обработчик `onEnded` в видеоплеере.
