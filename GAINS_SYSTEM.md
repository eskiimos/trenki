# Система начисления очков за просмотр видео

## Описание
Система автоматически начисляет очки характеристик при просмотре видео в приложении.

## Механизм работы

### 1. Условия начисления
- **80% просмотра** - для обычного просмотра видео (вне тренировки)
- **90% просмотра** - для видео в составе тренировки
- Начисление происходит один раз за видео

### 2. Файлы и компоненты

#### Видеоплеер (`src/app/video/[id]/page.tsx`)
- `gainsCreditedRef` - флаг для предотвращения повторного начисления
- `handleVideoProgress()` - проверяет прогресс просмотра
- `creditGainsForWatching()` - функция начисления очков
- Автоматический сброс флагов при смене видео

#### API эндпоинты
- `POST /api/training/complete-module` - начисление за модуль/видео
  - Создает запись в CharacteristicHistory
  - Обновляет характеристики профиля
  - Лимит: 4 модуля в день

- `GET /api/profile/recent-gains` - получение последних приростов
  - Возвращает историю приростов (по умолчанию 10 записей)
  - Суммирует общий прирост по каждой характеристике

#### Профиль (`src/app/profile/page.tsx`)
- Отображает прирост под каждой характеристикой
- Формат: `+X.XX` зеленым цветом
- Автоматическая загрузка при открытии профиля

### 3. Типы начисления

#### Обычный просмотр (80%)
```typescript
if (!fromWorkout && progressPercent >= 80) {
  await creditGainsForWatching();
}
```

#### Тренировка (90%)
```typescript
if (fromWorkout && progressPercent >= 90) {
  await completeVideoInWorkout();
}
```

### 4. Расчет очков
Используется библиотека `lib/characteristics.ts`:
- **BASE_GAIN** = 0.5
- Формула с убывающей отдачей: `gain = BASE_GAIN * ((100 - current) / 100) * multiplier`
- Каждый LoadType влияет на определенные характеристики

Примеры:
- SPEED → +1.0 скорость, +1.0 выносливость
- POWER → +1.0 сила, +0.5 скорость
- ENDURANCE → +1.0 выносливость, +0.5 гибкость

### 5. История приростов (CharacteristicHistory)

Каждая запись содержит:
```typescript
{
  userId: string
  sessionId: string | null  // null для обычного просмотра
  eventType: 'MODULE' | 'WORKOUT'
  
  // Новые значения характеристик
  ratingPower: number
  ratingSpeed: number
  ratingEndurance: number
  ratingTechnique: number
  ratingFlexibility: number
  potential: number
  
  // Приросты
  gainPower: number
  gainSpeed: number
  gainEndurance: number
  gainTechnique: number
  gainFlexibility: number
  
  createdAt: DateTime
}
```

### 6. UI/UX

#### Видеоплеер
- Модальное окно с анимацией при начислении
- Уведомление toast о успехе/лимите
- Автоматическое обновление локального профиля

#### Профиль
- Прирост отображается под значением характеристики
- Зеленый цвет `text-green-400`
- Размер шрифта `text-[9px]`
- Отображается только если `gainX > 0`

### 7. Дневные лимиты
- **4 модуля** в день
- **2 тренировки** в день
- При достижении лимита показывается предупреждение
- Сброс в 00:00 по серверному времени

### 8. Примеры использования

#### Просмотр видео
1. Пользователь открывает видео в приложении
2. Видео проигрывается до 80%
3. Автоматически начисляются очки
4. Показывается модальное окно с приростом
5. Обновляется профиль

#### Проверка прироста
1. Пользователь открывает профиль
2. Под каждой характеристикой видит прирост
3. Например: "99" и под ним "+0.33"

### 9. Технические детали

#### Предотвращение дублирования
- `gainsCreditedRef` сбрасывается при смене видео
- API проверяет дневные лимиты
- История записывается один раз за событие

#### Оптимизация
- Кэширование Kinescope URL (1 час)
- Ограничение обновлений прогресса (каждые 5 секунд для тренировок)
- Лимит запросов к API

#### Обработка ошибок
- Try-catch в creditGainsForWatching()
- Toast уведомления об ошибках
- Логирование в консоль
