## 🧪 Как протестировать

### Шаг 1: Сгенерировать тренировку
1. Открыть `/training/assessment`
2. Ответить на вопросы и сгенерировать тренировку
3. Перейти на страницу тренировки `/training/workout`

### Шаг 2: Проверить визуализацию модулей
- Первый модуль должен быть активным (зеленая рамка, badge "▶ Текущий")
- Остальные модули заблокированы (темный overlay, иконка замка)
- При клике на заблокированный модуль → alert "Сначала завершите предыдущие модули"

### Шаг 3: Начать первое видео
1. Кликнуть на первый модуль
2. Откроется video player с параметрами `fromWorkout=true&sessionId={id}`
3. В консоли должно появиться: `🎬 Starting video in workout`

### Шаг 4: Проверить отслеживание прогресса
1. Включить видео и перемотать на 90%
2. В консоли должно появиться: `✅ Completing video in workout`
3. Через 1 секунду автоматический редирект на `/training/workout`

### Шаг 5: Проверить обновление статуса
1. После возврата на страницу тренировки первый модуль должен показывать:
   - Синий overlay
   - Badge "✓ Завершено"
2. Второй модуль становится активным:
   - Зеленая рамка
   - Badge "▶ Текущий"

### Шаг 6: Завершить все модули
1. Повторить шаги 3-5 для каждого модуля
2. После завершения последнего модуля тренировка должна быть отмечена как COMPLETED

## 📊 API endpoints

### POST `/api/training/update`
**Действия:**
- `start` - отметить начало видео
- `progress` - обновить прогресс просмотра
- `complete` - завершить видео

**Пример запроса:**
```json
{
  "sessionId": "cmh4qvhvn0001ymfk5kuz977o",
  "videoId": "cmh4mhkue0002y7fjypwuziw7",
  "action": "complete"
}
```

**Ответ при завершении:**
```json
{
  "success": true,
  "message": "Video completed",
  "currentVideoIndex": 1,
  "totalVideos": 4,
  "allCompleted": false
}
```

### GET `/api/training/current?userId={id}`
**Возвращает:**
- Активную тренировку (PENDING или IN_PROGRESS)
- Массив videos с полем `completed`
- Поле `currentVideoIndex` для отслеживания текущего видео

## 🎯 Ожидаемое поведение

### При просмотре видео:
1. **0-89%** - отправка progress каждые 5 секунд
2. **90%+** - автоматическое завершение и редирект
3. **100% (onEnded)** - также завершение и редирект

### На странице тренировки:
1. **Первый запуск** - первый модуль активен, остальные заблокированы
2. **После завершения видео** - завершенный модуль помечен, следующий активен
3. **При возврате** - автоматическая перезагрузка данных
4. **Все завершены** - workout.status = COMPLETED

## 🐛 Возможные проблемы

### Проблема 1: Видео не завершается
**Решение:** Проверить в консоли, вызывается ли `handleVideoProgress()` при timeupdate

### Проблема 2: Не показывается заминка
**Решение:** ✅ Исправлено - изменили условие RPE с 4 на 5

### Проблема 3: Модули не обновляются после возврата
**Решение:** Проверить, срабатывает ли event listener visibilitychange

### Проблема 4: Можно открыть заблокированный модуль
**Решение:** Проверить логику `isLocked` в workout/page.tsx
