# Демонстрация логики первого запуска

## ✅ На главной странице реализована условная логика:

### 📱 **Первый запуск (новый пользователь):**
- Показывается только **имя пользователя** из Telegram
- **Скрыты:** номер игрока, позиция, блок "потенциал"
- Пример: "АЛЕКСАНДР" (без номера и позиции)

### 🏒 **После заполнения профиля:**
- Показывается **номер** (например, 88)
- Показывается **позиция** (ВР, ЗАЩ, ЛК, Ц, ПК)
- Показывается **блок потенциала** с иконкой молнии
- Пример: "88 ВР КОНСТАНТИН КОНСТАНТИНОПОЛЬСКИЙ" + потенциал

## 🔧 **Как это работает:**

1. **Компонент Header** проверяет статус профиля через API `/api/user/status`
2. **API проверяет** наличие `position` и `number` в профиле пользователя
3. **Условное отображение** на основе `hasCompleteProfile`

## 🎮 **Тестирование:**

- **Главная:** http://localhost:3001 - видна логика для нового пользователя
- **Debug:** http://localhost:3001/debug - подробная информация о статусе

## 📡 **Интеграция с Telegram:**

- Данные берутся из `window.Telegram.WebApp.initDataUnsafe.user`
- `first_name` и `last_name` подставляются автоматически
- При отсутствии Telegram данных показывается "Игрок"
