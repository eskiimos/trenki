# Персональные страницы тренеров - Руководство

## Что реализовано

Создана система персональных страниц тренеров с динамическими роутами:

### 1. Структура файлов
- `/src/app/trainers/page.tsx` - Список всех тренеров
- `/src/app/trainers/[id]/page.tsx` - Персональная страница тренера
- `/src/app/api/trainers/[id]/route.ts` - API для получения данных тренера

### 2. Функциональность

#### Страница списка тренеров (`/trainers`)
- Загрузка всех тренеров из базы данных
- Отображение карточек с основной информацией
- Переход на персональную страницу по клику
- Состояния загрузки и ошибок

#### Персональная страница тренера (`/trainers/[id]`)
- Подробная информация о тренере
- Статистика (опыт, количество видео, тренировок)
- Список видео тренера с превью
- Кнопка связи с тренером (заглушка)
- Адаптивный дизайн

### 3. Дизайн
Использован существующий дизайн системы:
- Темная цветовая схема (#101530, #060919)
- Акцентные цвета (#445CFF, #A1FF4A, #AEABBB)
- Типографика Overpass
- Система рейтингов со звездами
- Карточки с градиентами

## Как использовать

### Просмотр тренеров
1. Перейти на `/trainers`
2. Просмотреть список доступных тренеров
3. Кликнуть на карточку тренера для перехода на его страницу

### Персональная страница
- Просмотр полной информации о тренере
- Изучение списка его видео
- Переход к просмотру видео (ведет на `/video/[id]`)

## API Endpoints

### GET /api/trainers
Возвращает список всех тренеров с их видео

### GET /api/trainers/[id]
Возвращает подробную информацию о конкретном тренере:
- Данные тренера
- Список его видео
- Статистика (количество видео, тренировочных сессий)
