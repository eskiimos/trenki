# 🏷️ Автоматическая связь LoadType тегов с видео

## ✅ Что реализовано:

При сохранении или обновлении видео в админке **автоматически создаётся связь с LoadType тегом** на основе выбранного "Типа физической нагрузки".

---

## 🗺️ Маппинг типов нагрузки:

| Выбор в админке | LoadType enum | Влияет на характеристику |
|----------------|---------------|-------------------------|
| **Максимальная сила** | `MAX_STRENGTH` | 💪 Сила (`ratingPower`) |
| **Мощность** | `POWER` | 💪 Сила (`ratingPower`) |
| **Скорость** | `SPEED` | ⚡ Скорость (`ratingSpeed`) |
| **Силовая выносливость** | `STRENGTH_ENDURANCE` | 🫀 Выносливость (`ratingEndurance`) |
| **Анаэробная выносливость** | `ANAEROBIC_ENDURANCE` | 🫀 Выносливость (`ratingEndurance`) |
| **Аэробная выносливость** | `AEROBIC_ENDURANCE` | 🫀 Выносливость (`ratingEndurance`) |
| **Ловкость** | `AGILITY` | 🎯 Техника (`ratingTechnique`) |
| **Мобильность** | `MOBILITY` | 🤸 Гибкость (`ratingFlexibility`) |
| **Технические навыки** | `TECHNICAL_SKILL` | 🎯 Техника (`ratingTechnique`) |
| **Статическая растяжка** | `STATIC_STRETCH` | 🤸 Гибкость (`ratingFlexibility`) |
| **Динамическая растяжка** | `DYNAMIC_STRETCH` | 🤸 Гибкость (`ratingFlexibility`) |

---

## 🔧 Как это работает:

### 1. **Создание видео** (POST `/api/videos`)

```typescript
// Админ выбирает "Тип физической нагрузки" в форме
body.типНагрузки = "Мощность"

// Backend автоматически:
// 1. Маппит "Мощность" → "POWER"
// 2. Находит или создаёт тег "LoadType:POWER"
// 3. Создаёт связь VideoTag между видео и тегом
```

**Результат:**
- ✅ Видео создано
- ✅ LoadType тег привязан
- ✅ При завершении тренировки с этим видео прирост пойдёт в 💪 Сила

---

### 2. **Редактирование видео** (PUT `/api/videos/[id]`)

```typescript
// Админ меняет "Тип физической нагрузки"
body.типНагрузки = "Скорость" (было "Мощность")

// Backend автоматически:
// 1. Удаляет старый LoadType тег (LoadType:POWER)
// 2. Маппит "Скорость" → "SPEED"
// 3. Находит или создаёт тег "LoadType:SPEED"
// 4. Создаёт новую связь VideoTag
```

**Результат:**
- ✅ LoadType обновлён
- ✅ Теперь прирост пойдёт в ⚡ Скорость

## 📊 Структура данных:

### Tag (LoadType тег)
```prisma
{
  id: "cmhn...",
  name: "LoadType:POWER",      // Уникальное имя тега
  displayName: "POWER",         // Отображаемое имя
  tagType: "LOAD",              // Тип тега (из enum TagType)
  loadType: "POWER",            // Конкретный тип нагрузки (из enum LoadType)
  order: 0
}
```

### VideoTag (связь видео-тег)
```prisma
{
  videoId: "cmhn...",
  tagId: "cmhn...",
  // Уникальная пара (videoId + tagId)
}
```

## 📝 Примечания:

- **Старые теги**: Поле `Video.tags` (строковый массив) сохранено для обратной совместимости
- **Новая система**: Использует связи `VideoTag` → `Tag` через Prisma relations
- **Миграция**: Старые видео можно обновить через админку (просто открыть и сохранить)
- **Валидация**: Если `типНагрузки` не указан, LoadType тег не создаётся
