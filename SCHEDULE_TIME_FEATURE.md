## Как работает

1. Пользователь открывает видео и нажимает "Добавить в календарь"
2. Выбирает одну или несколько дат в календаре
3. **НОВОЕ**: Под календарём появляется секция "НАЧАЛО" с кнопкой времени
4. **НОВОЕ**: При клике на кнопку открывается Time Picker с прокруткой
5. Пользователь выбирает часы и минуты
6. Нажимает "СОХРАНИТЬ"
7. **НОВОЕ**: После сохранения показывается превью видео с датой и временем
8. В календаре тренировки отображаются с временем начала

## Технические детали

- **Time Picker стиль**: Использует gradient mask для fade-эффекта
- **Скролл**: Snap-to-center для удобного выбора
- **Время по умолчанию**: 09:00 для будущих дат, текущее время + 1 час для сегодняшнего дня
- **Формат времени**: 24-часовой формат (HH:MM)
- **Цвет времени в списке**: #A1FF4A (зеленый)
- **API**: Время сохраняется в ISO формате с датой

## Валидация времени и даты

✅ **Нельзя выбрать прошедшие даты**
- Прошедшие дни в календаре затемнены (opacity: 30%)
- Кнопки прошедших дат заблокированы (disabled)
- Клик на прошедшую дату игнорируется

✅ **Нельзя выбрать прошедшее время для сегодняшнего дня**
- При попытке сохранить показывается ошибка: "Нельзя выбрать прошедшее время"
- Кнопка времени подсвечивается красной рамкой при ошибке
- Автоматическая установка времени на час вперед при выборе сегодняшней даты

✅ **Умная установка времени**
- Для будущих дат: 09:00
- Для сегодняшней даты: текущее время + 1 час
- Если уже поздно (после 23:00): устанавливается 23:00
